Humans review before any RAM sees anything

Every idea handed in here lands in a private, human-reviewed queue first. No submission reaches a RAM automatically: a person reads it, decides whether it is worth a RAM's time, and only then, if approved, does it get attached to one.

That is not a formality. It is the safety boundary that keeps this system honest. Nobody outside that review step can direct what a RAM works on, including viewers asking the Herder questions.

Handing in is client-side only until the real backend answers: the queue position shown here is a placeholder count. See the README for exactly what switches over and how.

HashRammers funds real attempts against HashSmash. Results count only when HashSmash says they count.
